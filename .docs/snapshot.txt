Two-dimensional array in strings.

hh: Hour; range: [0–24]  
mm: Minute; range: [0–59]  
ss: Description; ranges [0 to 59] 
Mask: record type. 
Meaning of each bit: 
Bit0: Normal snapshot 
Bit1: Motion detection snapshot 
Bit2: Alarm snapshot 
Bit3: Card-swiping snapshot 
Bit6: POS snapshot
