# DahuaCamControl

Локальное Windows-приложение (Python + tkinter) для управления въездными воротами
через камеры Dahua с распознаванием автомобильных номеров (ANPR).

## Возможности

- **1 или 2 камеры**: вторая панель появляется автоматически, если в конфиге заполнены
  её креды (ip/username/password);
- **live-видео** каждой камеры (MJPEG-поток `/cgi-bin/mjpg/video.cgi` — без ffmpeg/VLC);
- **кнопка «ОТКРЫТЬ ВОРОТА»** на каждой панели (`trafficSnap.cgi?action=openStrobe`,
  раздел 10.4.1 HTTP API Dahua V3.52);
- **фото последнего распознанного автомобиля** под видео в уменьшенном вдвое формате;
- **крупная строка с распознанным номером** + метка «ЕСТЬ/НЕТ в справочнике
  разрешённых номеров» (сравнение нечувствительно к регистру, кириллица↔латиница);
- справочник номеров: добавление в один клик с панели, ручной ввод, удаление;
- журнал событий (ANPR и открытия ворот) в GUI и в файле `gate_log.jsonl`.

ANPR-события принимаются подпиской `snapManager.cgi?action=attachFileProc`
(разделы 4.4.3 и 10.1 API): multipart-ответ содержит текстовые части с полями
`Events[...].TrafficCar.PlateNumber=...` и JPEG-снимок автомобиля.

## Установка

```bat
python -m pip install -r requirements.txt
copy config.example.json config.json
:: отредактируйте config.json: ip/username/password камеры 1 (обязательно)
:: и камеры 2 (опционально — панель появится только при заполненных кредах)
python app.py
```

Зависимости: Python 3.10+ (tkinter включён), `requests`, `Pillow`.
Никаких дополнительных кодеков не требуется — видео приходит JPEG-кадрами по HTTP.

## Конфигурация (config.json)

| Ключ | Назначение |
|---|---|
| `cameras` | массив из 2 камер: `name`, `ip`, `username`, `password`, `channel` (с 1). Камера отображается, только если заполнены ip/username/password |
| `video.width/height` | размер окна видео в GUI (фото авто — вдвое меньше) |
| `video.subtype` | 0 — основной поток, 1 — подпоток (рекомендуется для GUI) |
| `anpr_events` | коды событий для подписки (по умолчанию `TrafficJunction`) |
| `heartbeat` | интервал heartbeat подписки событий, сек |
| `whitelist_file` | файл справочника разрешённых номеров |
| `log_file` | файл журнала (JSONL) |

## Проверка без камеры

```bat
python selftest.py
```

8 офлайн-проверок: нормализация номеров, справочник, multipart-парсер (MJPEG и
attachFileProc), извлечение номера, работа с изображениями, конфиг.

## Структура проекта

| Файл | Назначение |
|---|---|
| `app.py` | точка входа (запуск GUI) |
| `gui.py` | интерфейс: панели камер, журнал, справочник |
| `dahua_client.py` | клиент HTTP API Dahua (Digest-аутентификация), multipart-парсер, фоновые потоки видео/ANPR |
| `config.py` | загрузка/сохранение конфига, справочник номеров, JSONL-лог |
| `main.py` | консольный прототип (исторический, сохранён как есть) |
| `swagger.yaml` | OpenAPI-спецификация серверной версии (историческая) |
| `DAHUA_HTTP_API V3.52 for BITRU.pdf` | полная документация API экосистемы Dahua |

## Известные ограничения

- MJPEG-подпоток камеры даёт ~5–15 FPS; для 25 FPS основного потока нужен RTSP
  (ffmpeg/OpenCV) — в этой версии не используется намеренно (нулевые внешние
  зависимости медиа-стека);
- при незаполненных кредах камера пропускается (приложение работает с одной камерой);
- секреты хранятся в `config.json` локально (в .gitignore). Не публикуйте его.
